# YouTube Data API 사용량 계획 (변경 후)

> 작성 기준일: 2026-11-08 (KST) · 영상 6,413개(videos.json), ARTBEAT v 영상 60개
> 상태: **계획안**. 아직 워크플로/스크립트는 변경하지 않았음. 적용 후 실제 사용량은 Google Cloud Console에서 확인.

## 1. 한도

- 하루 기본 할당량: **10,000 유닛** (프로젝트 단위, 한국 시간 17:00에 초기화 = 태평양 시간 자정)
- 읽기 요청(`list`)은 호출당 **1유닛**, `search.list`만 호출당 **100유닛**
- 실제 한도는 Cloud Console › API 및 서비스 › YouTube Data API v3 › 할당량에서 확인 (기본값이 아닐 수 있음)

## 2. 워크플로별 1회 비용

| 워크플로 | 호출 구성 | 1회 유닛 |
|---|---|---|
| Sync Videos (`fetch-videos.yml`) | `playlistItems.list` 129회 + `videos.list` 129회 (영상 6,413개 ÷ 50) | **258** |
| Fetch ARTBEAT v videos | `playlistItems.list` 2회 + `videos.list` 2회 (영상 60개 ÷ 50 올림) | **4** |
| Fetch Channel Stats | `channels.list` 1회 | **1** |
| Check Live (수동 실행) | `search.list` 1회 | **100** |

## 3. 변경 후 실행 시각과 하루 사용량

| 워크플로 | 실행 시각 (KST) | `cron` (UTC) | 횟수/일 | 하루 유닛 |
|---|---|---|---|---|
| Sync Videos | 23:33, 06:33, 12:33, 18:33 | `33 14,21,3,9 * * *` | 4 | 4 × 258 = **1,032** |
| Fetch ARTBEAT v videos | 23:23 | `23 14 * * *` | 1 | 1 × 4 = **4** |
| Fetch Channel Stats | 23:13 | `13 14 * * *` | 1 | 1 × 1 = **1** |
| Check Live | 수동 (필요할 때만) | (예약 없음) | 0 | 0 (실행 1회당 +100) |
| **합계** | | | | **1,037 유닛 (한도의 약 10.4%)** |

- 남는 여유: 약 8,963 유닛 → Check Live를 수동으로 하루 최대 약 89회까지 더 돌려도 한도 안
- Check Live를 하루 3번 수동 실행하면 합계 1,337 유닛 (약 13.4%)

## 4. 변경 전후 비교

| 구분 | 변경 전 | 변경 후 |
|---|---|---|
| Check Live | 30분 주기, 최대 48회 × 100 = 4,800 | 수동 (0) |
| Sync Videos | 1회 × 258 = 258 | 4회 × 258 = 1,032 |
| ARTBEAT v | 1회 × 4 = 4 | 1회 × 4 = 4 |
| Channel Stats | 1회 × 1 = 1 | 1회 × 1 = 1 |
| **합계** | **최대 약 5,063 (50.6%)** | **약 1,037 (10.4%)** |

(Check Live는 예약 지연·누락으로 실제 실행 횟수가 48회보다 적었을 수 있음)

## 5. 규모가 커질 때

- 영상 1,000개 증가 시 Sync Videos 1회당 약 +40유닛 → 하루(4회) 약 +160유닛
- 영상이 약 60,000개가 되면 4회 합계가 약 10,000에 가까워짐 (현재 규모에서는 해당 없음)
- Sync Videos를 하루 N회로 바꾸면 하루 유닛 ≈ N × 258 + 5

| Sync Videos 횟수/일 | 하루 합계 | 한도 대비 |
|---|---|---|
| 1 | 약 263 | 2.6% |
| 4 (계획안) | 약 1,037 | 10.4% |
| 8 (3시간 주기) | 약 2,069 | 20.7% |
| 24 (1시간 주기) | 약 6,197 | 62.0% |

## 6. 확인 방법

1. Cloud Console › YouTube Data API v3 › 할당량 및 시스템 한도 › 일일 사용량 그래프
2. 계획안 적용 후 며칠 뒤 실제 사용량이 위 표(약 1,037)와 비슷한지 비교
3. `quotaExceeded`(403) 오류가 나면 Actions 로그에서 어떤 워크플로가 호출했는지 확인
